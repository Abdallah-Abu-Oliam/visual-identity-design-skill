In the logo, type becomes outline

A finished wordmark contains no live text. Rasterisers substitute whatever font they find — which distorts Latin letterforms and can break Arabic letter joining entirely, since Arabic shaping is contextual. Convert to paths before anything ships. export.sh refuses to run on an SVG still holding <text>.
