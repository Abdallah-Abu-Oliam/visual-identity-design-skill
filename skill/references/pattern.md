# Pattern

**Where ownability comes from.** Logo, colour and typography produce a competent identity.
They rarely produce a distinctive one.

---

## Why it exists — the boring test

Assemble the logo, the palette and the typeface, look at the result, and ask:

> **Could this belong to any identity?**

For Jamrah the answer was yes. Correct, competent, and completely generic — and **nothing
in it was wrong.** That is the trap. Correct-but-generic is the default output of a
competent process, and without a step that names it, it ships.

The pattern is the answer to that question.

---

## Two routes

Both work. Pick by what the brand actually has.

### Route A — from the brand's own material

Look at the thing itself. **جمرة is an ember, so the pattern came from the cracked surface
of burning coal** — لهب, the flame.

Ask: what is this brand physically made of, or made from, or used on? Steel grain, ember
cracks, woven fibre, sand ripple, grain of wood, the trace of a tool. **The material is
already the brand's; nobody else can take it without taking the brand.**

This is the same derivation as everything else — a concrete, drawable node from the mind
map becoming a graphic system.

### Route B — from an icon system

Design a set of icons, then repeat and combine them.

Saudi Founding Day built nine — Arabian horse, architectural ornament, calligraphy strokes,
falcon, fanjal, the first Saudi State flag, date palm, majlis, market — plus four seasonal.
The guideline states it plainly: *"These icons can be used individually or repeated together
to create a new pattern."* From that set they built **modular patterns** (grid-based, some
from a single repeated icon, some from several) and **circular patterns** (radial mixes).

**Scales further than Route A** — the set generates many patterns rather than one, and it
gives the brand an icon library at the same time. Costs more up front.

| | Route A — material | Route B — icon system |
|---|---|---|
| Source | The brand's physical world | A designed icon set |
| Output | One strong pattern | A family of patterns, plus icons |
| Effort | Lower | Higher |
| Best when | The brand has a distinctive material or process | The brand has many symbols worth carrying, or needs iconography anyway |

## Rules

**Name it.** لهب, not "the pattern". A named asset can be discussed, defended and reused.
The same reason art directions get names — an unnamed thing can only be reacted to.

**It is a register move, not a hue move.** A different orange is one variable a competitor
changes in an afternoon. A pattern derived from the brand's own material cannot be taken
back without abandoning their identity. **This is why the differentiation survives.**

**Apply it across the identity, not in one place.** Stationery, cards, letterhead,
packaging, social, backgrounds, signage. A pattern used once is decoration; used
consistently it becomes the thing people recognise before they read the name.

**Show before and after.** Assembly without it looks correct and generic; with it, ownable.
**The comparison is the argument** — it explains the pattern better than any paragraph, and
it is the same technique the reference guidelines use for misuses: put the two side by side
and let the eye decide.

**Specify correct and incorrect cropping.** Founding Day devotes a page to it. A pattern
cropped badly reads as a mistake rather than a system, so the guideline must show both.

**Never let it fight the content.** Discord's rule for its Community Pattern: always white
underneath content, colour only when the pattern stands alone. Whatever the equivalent is
here, decide it and write it down — a pattern that competes with the message has cost the
brand more than it gained.
